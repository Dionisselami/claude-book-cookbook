# Recipe 10 — From manuscript to shelf

**Fixes:** a finished book with nowhere to go.

## Before you export

1. Gate passed ([Recipe 07](07-scoring-gate.md)), all passes run ([Recipe 06](06-revision-passes.md)).
2. Front and back matter: title page, copyright page, dedication, and — for a novel — an author note.
   Cheap to write, and their absence is the first thing a reader notices.
3. Chapter headings consistent, files in reading order, one file per chapter or one combined file.
4. Read the first chapter, the last chapter, then a middle one. If the middle one reads like a
   different book, it is.

## Storefront notes

- **Amazon KDP** accepts AI-assisted work with disclosure at publish time. Answer the disclosure
  question inside the publishing flow; do not paste tool names into the book's description.
- **Series potential:** if the ending promises more, plan book two's premise now, while the voice is
  still in the files. The cheapest sequel you will ever set up.
- **Cover and blurb are not a one-prompt job.** The blurb is 150 words that must promise the book you
  actually wrote — generate it from `outline.md`, then cut it by a third.
- **Metadata beats marketing for a first book.** Correct categories, correct keywords, correct series
  links. See [`reference/publishing-checklist.md`](../reference/publishing-checklist.md).

## Done when

The manuscript exports cleanly, the storefront metadata is accurate rather than aspirational, and you
can name which parts a reader will quote.
