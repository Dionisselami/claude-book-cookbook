# Publishing checklist

Ordered, because the order is where people lose days.

## 1. Gate the manuscript

- [ ] `evaluate_book` passes
- [ ] All six revision passes run ([Recipe 06](../recipes/06-revision-passes.md))
- [ ] Last two chapters read by a human, in sequence
- [ ] Middle chapter spot-read against chapter 1 for voice drift

## 2. Make the files

- [ ] Title page, copyright page, dedication, author note
- [ ] Chapters in reading order, consistent heading style
- [ ] Front matter page numbers excluded; epigraphs if you use them
- [ ] Export readable format (`.docx` or plain structured text) — one file, not thirty
- [ ] Proof a random 10 pages on the actual e-reader or phone you own

## 3. Blurb

- [ ] Derived from `outline.md`, not from the ending
- [ ] 150 words, then cut by a third
- [ ] Promises the genre you actually wrote
- [ ] No tool names, no process talk, no "in a world where"

## 4. Metadata (this is what sells a first book)

- [ ] Two correct categories — the competition's categories, not aspiration
- [ ] Seven keyword slots, each a real search phrase
- [ ] Series name and reading order, if it is a series
- [ ] Language, region, age range correct
- [ ] Cover at the required dimensions and DPI

## 5. Publish

- [ ] AI-assistance disclosure answered in the publishing flow
- [ ] Pricing compared against the category's band, not against free
- [ ] Preview the sample download yourself, cover to first chapter
- [ ] Author page and series page linked

## 6. First two weeks

- [ ] Read your own reviews without replying to any of them
- [ ] Note the three most common complaints; they are usually structural, not stylistic
- [ ] Decide now whether the sequel premise is worth it — see
      [Recipe 10](../recipes/10-manuscript-to-shelf.md)
